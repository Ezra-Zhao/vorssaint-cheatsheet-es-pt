# 第一次选装演练 | First-setup drill: install only what you use

把「只装你用的」这条规矩一次走通，顺序别乱：

1. **装上**：`brew install --cask vorssaint`（或从 Releases 页下 .dmg 拖进 Applications）。先确认前提：Apple Silicon + macOS 14 或更新，不满足就别往下走。
2. **先别全开**：打开设置的功能页，先只勾你这周真会用的两三组（比如剪贴板历史 + 窗口吸附），其余组保持未安装——它们不会加载、不会出现在界面里、也不会跟你要权限。想省事可以先套预设再删。
3. **按提示授权限**：设置流程只会为你勾选的功能申请权限，逐条看清说明再授。没有启用的功能，一条权限都不要多给。
4. **去权限页验收**：打开权限页逐项核对——每条权限都应有功能在用；若某条已授权限显示「没有任何功能在用」，顺手用它给的快捷入口撤掉。
5. **一周后回看**：用满一周再回功能页：没碰过的组保持未安装，常的组（比如截图、卸载器）再补装——重装某功能会恢复它之前的设置，不用重配。目标是菜单栏里只留你真在用的那几件。
